# FIFA World Cup Ranking Analysis
**Tools:** Microsoft Excel
## Project Overview
Analyzed FIFA national team rankings using point totals, ranks, confederation groupings, and historical changes. The project compares current and previous performance and examines regional strength across confederations.
## What I Did
- Worked with multi-sheet FIFA ranking data in Excel for analysis.
- Compared current and previous team rankings and point totals.
- Analyzed ranking movement across different confederations.
- Examined regional strength using ranking and point data.
- Organized FIFA national team ranking data by points, rankings, confederations, and historical changes for analysis and visualization.
