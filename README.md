# FIFA World Cup Ranking Analysis

**Project:** FIFA World Cup Ranking Analysis  
**Tools:** Microsoft Excel  

Analyzed global FIFA national team rankings using point totals, ranks, confederation groupings, and historical changes. Cleaned and structured multi‑sheet data to compare current vs. previous performance, highlight regional strength, and reveal movement trends across all confederations.

## Files
- `FIFA-World-Cup.xlsx` — core ranking dataset  
- `screenshots/` — visual summaries of confederation totals and ranking comparisons
